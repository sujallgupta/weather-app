# 🌦️ Weather App

A simple and responsive **Weather App** built with **HTML, CSS, and JavaScript**.  
It provides **real-time weather details** like temperature, humidity, and conditions for any city, using the **Weather API from RapidAPI**.  

---

## ✨ Features
- 🌍 Search weather by **city name**
- 🌡️ Displays **temperature, weather condition, and humidity**
- 📍 Location-based weather (using geolocation) *(if added)*
- 📱 Responsive design for desktop and mobile

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**  
- **RapidAPI – Weather API**  

---

## 🚀 Getting Started

### Prerequisites
- A browser (Chrome, Edge, Firefox, etc.)
- An account on [RapidAPI](https://rapidapi.com/)  
- Subscribe to a weather API on RapidAPI (e.g., *OpenWeatherMap on RapidAPI* or *Weather by API Ninjas*)  
- Get your **X-RapidAPI-Key** and **X-RapidAPI-Host** values
